# Model Artifacts

This directory contains the locked model and preprocessing artifacts used by the research demonstrator.

* Logistic regression model: Generates the model’s prediction output.
* Preprocessor: Applies the fitted transformations required by the model.

These artifacts must be used together with the corresponding metadata, input schema, and governance checks maintained elsewhere under demonstrator/artifacts/.

The model is intended for research and demonstration only. It is not a clinical diagnostic tool.
