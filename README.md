# Explainable Healthcare Risk Prediction using Machine Learning

## Overview

This project explores interpretable machine learning approaches for healthcare risk prediction using NHANES population health data.

The objective is to develop predictive models while improving transparency and understanding of the factors influencing healthcare risk predictions.

## Dataset

Source:
NHANES (National Health and Nutrition Examination Survey)

Data includes:
- Demographic information
- Body measurements
- Laboratory biomarkers
- Health questionnaire responses

## Objectives

- Perform healthcare data analysis
- Develop machine learning prediction models
- Apply Explainable AI techniques
- Analyse important healthcare risk factors
- Investigate relationships influencing model predictions
