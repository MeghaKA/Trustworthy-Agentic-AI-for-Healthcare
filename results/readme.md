# Research Results

This directory contains selected research evidence from the notebook workflow.

## Contents

* notebook4_explanation_consistency/ — Aggregate SHAP-based explanation evidence from exploratory analysis.
* notebook5_trust_fairness_safety/ — Integrated trustworthiness and fairness evidence.
* notebook7_cds_prototype/ — Clinical decision-support safety and evidence-provenance specifications.
* notebook8_agent_workflow/ — Agent specifications and workflow validation evidence.
* notebook9_final_integration/ — End-to-end integration and model-integrity audit results.

Only selected research outputs are retained. Intermediate files, duplicate artifacts, and participant-level result tables are excluded to keep the repository focused.

## Explainability Methods

Notebook 4 explores SHAP-based explanations. Notebook 6 and the deployed demonstrator use an exact logistic-regression coefficient-by-transformed-feature contribution decomposition. These are distinct methods.
