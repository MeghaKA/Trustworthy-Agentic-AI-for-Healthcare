# Research Figures

This directory contains selected figures from the nine-stage research workflow.

## Organization

* nb2/ — Data-quality and missingness analysis
* nb3/ — Predictive-model evaluation
* nb5/ — Trust, fairness, and safety evaluation
* nb6/ — Explainability consistency and stability

Only selected, research-relevant figures are retained. Intermediate plots and redundant visualizations are excluded.

Figures in nb4/ are not included in the current curated set because its SHAP plots were exploratory and were not adopted by the deployed demonstrator.

## Methodological Note

Notebook 4 explored SHAP-based explanations. Notebook 6 and the deployed demonstrator use an exact logistic-regression coefficient-by-transformed-feature contribution decomposition. These are different methods and should not be described interchangeably.
